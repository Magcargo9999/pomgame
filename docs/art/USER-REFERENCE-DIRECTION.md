# 사실적 픽셀 아트 방향 — 2026-11-18

사람은 첨부한 돼지 픽셀 그림과 해부 비율 그림처럼 사실적으로 작업하라고 지시했다. 기존 큰 머리·짧은 몸의 32px 만화형과는 다른 방향이다.

새 기준은 긴 성체 몸통, 실제 관절과 다리 비율, 작은 눈, 자연스러운 주둥이, 처진 귀, 어깨·넓적다리·배의 입체 명암이다. 두 번째 참고의 워터마크나 선화는 자산에 복사하지 않는다.

`pig_adult_realistic`은 이 방향을 확인하기 위한 별도 개정이다. 128×128 셀, 앵커 [64,119], 512×1920 시트를 쓴다. 팔레트·품종·프레임 순서·타이밍·무늬 레이어·좌우 반전 방식은 기존 데이터 형식을 유지한다. 기준 포즈 세 장만 생성하고 애니메이션은 픽셀 변환으로 파생한다.

`SPRITE-SPEC.md` 원문을 임의 변경하지 않았다. 기존 32px 시트는 프로토타입 호환 자산으로 보존한다. 실제 게임에 새128px 텍스처를 도입할 때는 메타데이터의 원본 셀 크기와 월드 표시 크기를 분리해야 한다. 셀128, 월드32로 사용하면 텍스처 밀도는4이며 확대할 때 디테일이 유지된다. 통합 방식은 god과 프런트엔드가 결정한다.

팔레트의 유일한 기준은 `palette-realistic.json`, 품종의 기준은 `breeds-realistic.json`이다. 빌더는 두 JSON을 읽으며 품종 데이터를 덮어쓰지 않는다. 종이 추가될 때는 새 시트·메타데이터·필요한 색 슬롯 데이터를 추가하고 공통 렌더러를 유지한다.
