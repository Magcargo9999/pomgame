# 자돈 스프라이트 보고서

## ART-4 후속 보완

뒷면의 분리된1px 점을 지우고 엉덩이 외곽을 연결했다. 측면의 발끝2px는 뒤쪽 다리에 연결했다. 애니메이션 편집 후 생기는 작은 대각선 분리는 최대1px의 빈 곳만 연결하고, 멀리 떨어진 작은 점은 제거한다. 큰 신체 조각이 분리되면 자동으로 삭제하지 않고 오류를 낸다.

39프레임 전체에 불투명 실루엣이 정확히 하나인지 회귀 시험을 추가했다. 자돈 몸 크기·접지·팔레트·무늬 합성·14개 PNG 검사와 HTML20조합도 다시 확인했다. 임시 파일 시험은 main에 포함된 개별 mkdtemp 폴더 방식을 사용하고 병렬 실행을 포함해3회 연속 통과했다.

main255baaf 병합 후 전체 node --test는 UI 경로 시험이 `(14,5)`에서 막혀 실패했다. 상세 로그는 `art4-tests-1.txt`에 있고 god에게 전달한다. 이 보고서는 전체 게임 시험이 통과했다고 주장하지 않는다.

최신 god 결정에 따라128px 사실형은 프로토타입에서 제외하며 기존 파일만 보존한다. 추가 이미지 생성은 중단했다. 이후에는 art-inbox의 외부 제작 파일을 가져오는 작업을 맡는다.

프로토타입용32px 호환 자산과, 사람의 사실적 참고 화풍을 보존하는128px 시안을 함께 제작했다.

- `assets/sprites/pig/piglet.png`: 128×480, 셀32×32, 앵커 [16,29], 15행·39프레임.
- `piglet.json`, `.spots.png`, `.belt.png`, `.points.png`: 기존 성체와 같은 행·슬롯·타이밍 형식.
- `art-review/piglet_x8.png`, `piglet.html`: 듀록 색 x8 시트와 독립 실행 애니메이션 검수.
- `piglet_realistic` 접두어의 PNG·JSON·무늬·x8·HTML: 셀128, 원본 체형 디테일 보존용 별도 개정.

## 검증

`node tools/validate-pig.cjs piglet`: 원본·무늬·합성·기준포즈·x8 총14건 통과. 알파·팔레트·12색 제한·고립 픽셀·외곽선·접지·투명 빈 칸에 실패가 없다. x8 최근접 확대 불일치0개.

`node --test tools/sprite-validate.test.cjs`: 8건 통과. 자돈 idle 3방향 몸 영역은15~17×12px로 규격14~18×11~14를 만족한다. 코와 눈 가독성 보완은 기준포즈별11·0·13픽셀이다.

브라우저 결과는 `piglet.browser.json`, 자동 결과는 `piglet.validation.json`에 있다. 품종5×무늬4의20조합, 프레임 선택, 좌우 반전, happy 1회 착지 종료, breeds.json 재로드를 검사했다. `piglet_realistic.validation.json`과 `.browser.json`에도 별도 검증 결과를 기록했다.

## 제작과 시각 범위

- [x] 자돈의 방향별 idle3장만 이미지 생성했다. 나머지39프레임은 공통 픽셀 편집기로 파생했다.
- [x] 자연스러운 어린 돼지의 몸·다리·귀 비율을 상세 기준포즈에 반영했다.
- [x] 32px 호환 기준포즈는 최빈색으로16×12 몸에 맞추고 코·눈을 보완했다. 평균 축소를 쓰지 않았다.
- [x] 같은 마커·무늬 형식으로5품종을 재사용할 수 있다.
- [ ] 32px 버전은 상세 참고의 피부 질감과 관절 디테일이 대부분 줄어든다. 사실형 최종 디테일로 승인하지 않으며128px 시안을 함께 제공한다.
- [ ] 128px 먹기·걷기는 픽셀 관절 마스크의 후속 시각 정리가 필요하다. 자동 검사 통과와 최종 애니메이션 승인을 구분한다.

사람에게 추가 승인을 요청하지 않고 작업을 진행했다. 게임 통합의 원본 픽셀 밀도 선택은 god과 프런트엔드가 결정한다. 생성 원본·정규화 과정은 `piglet-keyposes/`, `piglet-compat-keyposes/`에 보존했다.
